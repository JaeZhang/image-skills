# Style options / 光线、材质、配色与构图选项

Choose one option from each dimension instead of stacking many abstract adjectives. Start with the product and image role; then choose light, material treatment, palette, and composition.

## Light / 光线

| Option | Visual result / 视觉效果 | Best for / 适合 | Avoid when / 不适合 |
|---|---|---|---|
| Soft catalog / 均匀柔光 | clean, bright, readable / 干净明亮 | books, packaging, white-background hero / 图书、包装、白底主图 | strong texture or drama / 强纹理或戏剧感 |
| Directional side / 侧前方柔光 | volume and texture / 体积与纹理 | bags, corduroy, knit, apparel, leather / 包袋、灯芯绒、针织、服装、皮革 | highly reflective mirror surfaces / 镜面反光产品 |
| Rim light / 轮廓光 | edge separation and metal definition / 边缘分离、金属轮廓 | jewelry, dark bags, black apparel / 饰品、深色包、黑色服装 | label-heavy flat artwork / 需要均匀标签的平面图 |
| Diffuse top light / 顶部漫射光 | even flat-lay exposure / 均匀平铺 | variant grids, clips, jewelry sets / 合集、发夹、饰品 | dimensional hero shots / 强立体单品 |
| Dramatic stage / 戏剧舞台光 | cinematic movement / 电影感与动作 | cosplay and dynamic costume scenes / COS、动态服装 | white-background catalog images / 白底目录图 |
| Window natural / 窗边自然光 | warm lived-in mood / 温暖生活感 | ceramics, home goods, lifestyle bags / 陶瓷、家居、生活方式包袋 | strict multi-item exposure matching / 严格一致曝光的合集 |

## Material treatment / 材质表现

| Material | Prompt focus / 提示重点 | Products / 适合 |
|---|---|---|
| Textile fiber / 纤维纹理 | directional side light, visible weave, believable folds / 侧光、织纹、自然褶皱 | canvas, corduroy, knit, linen / 帆布、灯芯绒、针织、亚麻 |
| Metal highlight / 金属高光 | broad edge highlight, continuous reflection, no clipping / 宽边缘高光、连续反射、不死白 | silver, hardware, metal jewelry / 银饰、五金、金属饰品 |
| Ceramic glaze / 陶瓷釉面 | smooth tonal gradient and controlled reflection / 平滑渐变、受控反射 | cups, vases, tableware / 杯子、花瓶、餐具 |
| Paper print / 纸张印刷 | even light, flat plane, sharp artwork / 均匀柔光、平整、图案清晰 | books, cards, printed goods / 图书、卡片、印刷品 |
| Glossy packaging / 亮面包装 | controlled specular highlights, label clarity / 控制高光、标签清晰 | beauty and skincare packaging / 美妆护肤包装 |
| Matte surface / 哑光表面 | low-contrast light, fine non-plastic surface / 低对比柔光、细腻不塑料 | matte boxes, clay, matte cosmetics / 哑光包装、陶土、哑光彩妆 |

## Palette / 配色

| Option | Formula / 配方 | Best for / 适合 |
|---|---|---|
| Clean commercial / 白底商业 | product color + white/warm white/light gray / 产品色+白/暖白/浅灰 | books, beauty, kids, SKU / 图书、美妆、儿童、SKU |
| Warm handmade / 暖灰手作 | product color + warm gray/cream + light wood / 产品色+暖灰/米色+浅木 | bags, ceramics, handmade goods / 包袋、陶瓷、手作 |
| Dark luxury / 深色奢华 | product color + burgundy/brown/charcoal + one warm highlight / 产品色+酒红/深棕/深灰+单一暖色高光 | cosplay, leather, premium jewelry / COS、皮革、高端饰品 |
| Muted natural / 低饱和自然 | product color + sage/sand/cream / 产品色+灰绿/沙色/奶油色 | medieval apparel, linen, home goods / 中世纪服装、亚麻、家居 |
| Playful bright / 童趣明亮 | white/light base + 2–3 soft color blocks / 白底+2–3个柔和色块 | books, toys, learning products / 图书、玩具、学习用品 |
| Tone-on-tone / 同色系 | same hue, separated by luminance and rim light / 同色系但用明度和轮廓光分离 | editorial fashion, brand scenes / 编辑感服装、品牌场景 |

## Composition / 构图

| Option | Logic / 逻辑 | Best for / 适合 |
|---|---|---|
| Centered hero / 居中主图 | one focal point, readable silhouette / 单一焦点、轮廓清楚 | single bags, cups, packaging / 单个包袋、杯子、包装 |
| Off-center with copy space / 偏心留白 | subject 65–75%, reserve 15–30% on one side / 主体65–75%，一侧留15–30% | listing hero, brand image / 主图、品牌图 |
| Rule of thirds / 三分法 | dynamic balance and lifestyle context / 动态平衡、生活情境 | lifestyle and apparel / 场景图、服装 |
| Diagonal / 对角线 | movement and directional energy / 动势和方向感 | cosplay, long bags, action poses / COS、长包、动作图 |
| Triangle grouping / 三角构图 | stable relationship among three objects / 三个物体稳定关联 | cup or beauty sets / 杯子套装、美妆套装 |
| Grid flat lay / 规则网格 | comparison and consistent spacing / 便于比较、间距一致 | variants, jewelry, clips, books / 款式合集、饰品、发夹、图书 |
| Asymmetric flat lay / 错落平铺 | controlled rhythm without random clutter / 有节奏但不凌乱 | handmade and accessory sets / 手作、饰品合集 |
| Three-quarter view / 3/4视角 | shows front and depth / 同时展示正面与体积 | bags, cups, shoes, boxes / 包袋、杯子、鞋、盒装 |
| Macro detail / 局部特写 | one selling feature per frame / 每张只突出一个卖点 | seams, fibers, glaze, hardware / 缝线、纤维、釉面、五金 |

## Ready presets / 快速预设

| Preset | Light | Material | Palette | Composition | Products |
|---|---|---|---|---|---|
| Clean commercial / 干净商业 | soft catalog | paper or controlled package | clean commercial | centered hero | books, beauty, SKU |
| Warm handmade / 温暖手作 | directional side | textile, leather, ceramic | warm handmade | off-center or 3/4 | bags, ceramics, home |
| Metal premium / 金属精品 | rim + soft fill | metal highlight | cool neutral | grid or macro | jewelry, hardware |
| Dark editorial / 深色编辑 | key + rim | leather, textile, metal | dark luxury | thirds or diagonal | cosplay, premium fashion |
| Playful kids / 童趣明亮 | soft catalog | paper, matte surface | playful bright | grid or four-panel | children’s products |
| Cinematic action / 电影动态 | dramatic stage | costume and prop texture | cool light + dark base | diagonal action | cosplay scenes |

## Selection rule / 选择规则

Choose one light, one material treatment, one palette, and one composition. If two choices conflict, keep the product-appropriate light and the clearest composition. Do not use every option at once.

# 光线、材质、配色与构图选项

每次出图从每个维度选一个，不要堆叠所有风格词。先确定产品和图片用途，再选择光线、材质表现、配色和构图。

## 光线

| 选项 | 视觉效果 | 适合产品 |
|---|---|---|
| 均匀柔光 | 干净、明亮、信息清晰 | 图书、美妆、白底主图、儿童产品 |
| 侧前方柔光 | 有体积和纹理 | 包袋、灯芯绒、针织、服装、皮革、陶瓷 |
| 侧后方轮廓光 | 勾勒边缘和金属高光 | 银饰、深色包、黑色服装 |
| 顶部漫射光 | 平铺曝光均匀 | 饰品、发夹、款式合集、组合图 |
| 戏剧舞台光 | 动态、电影感 | COS、角色服装、动漫展场景 |
| 窗边自然光 | 温暖、生活化 | 陶瓷、家居用品、生活方式包袋 |

## 材质表现

| 选项 | 提示重点 | 适合产品 |
|---|---|---|
| 纤维纹理 | 方向性侧光、织纹、自然褶皱 | 帆布、灯芯绒、毛衣、亚麻 |
| 金属高光 | 宽边缘高光、连续反射、不过曝 | 银饰、五金、金属饰品 |
| 陶瓷釉面 | 平滑渐变、受控反射 | 杯子、花瓶、餐具 |
| 纸张印刷 | 均匀柔光、平整、图案清晰 | 图书、卡片、印刷品 |
| 亮面包装 | 控制高光、标签清晰 | 美妆护肤包装 |
| 哑光表面 | 低对比柔光、避免塑料感 | 哑光包装、陶土、哑光彩妆 |

## 配色

| 选项 | 配方 | 适合产品 |
|---|---|---|
| 白底商业 | 产品色 + 白/暖白/浅灰 | 图书、美妆、儿童、SKU |
| 暖灰手作 | 产品色 + 暖灰/米色 + 浅木色 | 包袋、陶瓷、手作 |
| 深色奢华 | 产品色 + 酒红/深棕/深灰 + 单一暖色高光 | COS、皮革、高端饰品 |
| 低饱和自然 | 产品色 + 灰绿/沙色/奶油色 | 中世纪服装、亚麻、家居 |
| 童趣明亮 | 白底 + 2–3 个柔和色块 | 儿童图书、玩具、学习用品 |
| 同色系 | 同色相，用明度和轮廓光分离 | 编辑感服装、品牌场景 |

## 构图

| 选项 | 画面逻辑 | 适合产品 |
|---|---|---|
| 居中主图 | 单一焦点、轮廓清楚 | 单个包袋、杯子、包装 |
| 偏心留白 | 主体 65%–75%，一侧留 15%–30% | Listing 主图、品牌图 |
| 三分法 | 动态平衡、适合生活场景 | 场景图、服装 |
| 对角线 | 有动势和方向感 | COS、长包、动作图 |
| 三角构图 | 三个物体关系稳定 | 杯子套装、美妆套装 |
| 规则网格 | 方便比较、间距一致 | 款式合集、饰品、发夹、图书 |
| 错落平铺 | 有节奏但不随机 | 手作、饰品合集 |
| 3/4 视角 | 同时看到正面和体积 | 包袋、杯子、鞋、盒装 |
| 局部特写 | 每张只突出一个卖点 | 缝线、纤维、釉面、五金 |

## 快速预设

- 干净商业：均匀柔光 + 纸张/包装 + 白底商业 + 居中主图。适合图书、美妆、SKU。
- 温暖手作：侧前方柔光 + 纤维/皮革/陶瓷 + 暖灰手作 + 偏心或 3/4。适合包袋、陶瓷和家居。
- 金属精品：轮廓光 + 金属高光 + 冷中性背景 + 网格或特写。适合银饰和五金。
- 深色编辑：主光加轮廓光 + 皮革/织物/金属 + 深色奢华 + 三分法或对角线。适合 COS 和高级服装。
- 童趣明亮：均匀柔光 + 纸张/哑光 + 童趣明亮 + 网格或四宫格。适合儿童产品。
- 电影动态：戏剧舞台光 + 服装和道具纹理 + 冷色光加深色底 + 动态对角线。适合 COS 动作场景。

如果两个选项互相冲突，优先保留适合产品材质的光线和最清楚的构图。
